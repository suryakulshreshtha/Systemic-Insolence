Every few years a platform I write on changes its mind about what it is. The
feed reorders itself, a paywall appears, the export button quietly stops
working. So this is mine. Plain HTML, my own domain, a file for every post.

Here is what that means in practice. This page is a Markdown file in a Git
repository. Publishing it was a commit. If this site disappears tomorrow, every
word still exists on my laptop in a format I can read without any software at
all.

## Things I intend to put here

Short notes, mostly. Weather, coffee, films, whatever I am reading. Longer
pieces when something is worth the effort. Build notes when I ship a side
project.

No schedule, no newsletter, no growth plan. Just somewhere to put things down.
